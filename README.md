# Piedra, Papel o Tijera con Copilot

Este proyecto es una introducción práctica a GitHub Copilot: usamos un asistente de programación para crear un juego de Piedra, Papel o Tijera, probarlo, localizar y corregir un error, y añadir una mejora a la interfaz.

El juego funciona directamente en el navegador y está construido con HTML, CSS y JavaScript, sin dependencias ni instalación.

## El recorrido del proyectos

1. **Conocer Copilot:** explorar cómo un asistente de programación puede ayudar a desarrollar una idea mediante instrucciones en lenguaje natural.
2. **Crear un juego:** construir una versión jugable de Piedra, Papel o Tijera contra la computadora.
3. **Corregir errores:** analizar un problema en la lógica de las jugadas y corregirlo para que cada botón envíe la opción seleccionada.
4. **Modificar el proyecto:** añadir un botón para alternar entre modo oscuro y modo claro, adaptando los colores de toda la interfaz.

## Cómo jugar

Abre `index.html` en cualquier navegador moderno. No necesitas instalar paquetes, iniciar un servidor ni configurar credenciales.

1. Elige piedra, papel o tijera.
2. La computadora escogerá una opción al azar y se mostrará el resultado de la ronda.
3. El marcador se actualiza con las victorias. Usa **Reiniciar partida** para empezar de nuevo.
4. Pulsa **Modo claro** o **Modo oscuro** para cambiar la apariencia.

## Archivos del proyecto

- `index.html`: estructura de la página, controles y contenido del juego.
- `styles.css`: diseño responsive, estilos y paletas de los temas claro y oscuro.
- `script.js`: reglas del juego, marcador, reinicio y alternancia de tema.
